## examples/

`examples/` 不属于外部参考库，是本次工作流生成的陆思妍系列示例。仅用于学习网格、字体层级、渐变与质检，不得把示例署名或人物风格套用到其他人物。

所有外部参考仅用于设计研究与内部参考。需要公开发布或商业复用具体参考图时，应另行确认原作者授权。
